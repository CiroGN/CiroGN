### 🩺 TCC — Fine-tuning QLoRA para triagem médica em PT-BR

Pipeline completo de fine-tuning do `Qwen3.5-0.8B` no dataset **MedPT** (384 mil pares de Q&A médicos) para classificar a especialidade médica adequada a partir da queixa do paciente — tudo rodando em **GPU consumer (RTX 4070 12 GB)**.

<div align="center">

| Setup | Accuracy | F1 Macro |
|:---|:---:|:---:|
| Zero-shot | 22,4% | 0,190 |
| Three-shot | 15,0% | 0,186 |
| Five-shot | 14,8% | 0,175 |
| 🏆 **Fine-tuned (QLoRA)** | **66,8%** | **0,630** |
